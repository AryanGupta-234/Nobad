# NOBAD Find 0.7.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship NOBAD Find 0.7.0: smart resource governor with per-app memory, strict process lifecycle and
watchdog, full transparency on the Indexing page, quick find bar, splash, new home and Settings pages.

**Architecture:** A governor thread turns live sensor samples into a work level (Full/Gentle/Light/Paused) with
a reason; the indexer obeys the level instead of today's on/off pauses. All Find processes live in an outer
kill-on-close job; background workers (readers, OCR, photo, new meaning worker) live in a nested worker job whose
CPU cap follows the level. The UI polls an extended `Api.status()`.

**Tech Stack:** Python 3.11, ctypes Win32 (kernel32/user32/pdh/dxgi), pywebview 6 (WebView2), onnxruntime,
pytest, PyInstaller + Inno Setup.

**Spec:** `docs/superpowers/specs/2026-11-18-find-governor-transparency-models-design.md` (sections 1, 2, 3, 5,
6, and the hardware scan from 4 shown as information only). Model tiers, consent dialogs and vector rebuild are
0.8.0 and NOT in this plan.

## Global Constraints

- Work in `apps/find/` on branch `find-0.6.2` (already has the query/Enter fixes, commit f9cc617).
- Test: `cd apps/find && .venv-build/Scripts/python.exe -m pytest -q tests` and
  `.venv-build/Scripts/python.exe -m pyflakes nobadfind tests` (no output). Keep all 136 existing tests green.
- Windows-only code paths are guarded by `winapi.WIN`; tests that need real Windows APIs are marked
  `@pytest.mark.skipif(not winapi.WIN, reason="Windows only")`.
- No new outbound connection. No new runtime dependency unless the task says so (no psutil).
- Find only ever limits or kills its own processes. Never touch other apps.
- Learned app profiles store the exe file name only (lowercase, e.g. `forzahorizon5.exe`), never paths or titles.
- UI: strict CSP (`script-src 'self'`, no inline script/style attributes that need `unsafe-inline`), NOBAD style
  in `ui/app.css` (one NOBAD orange, dark/light, glass). UI tasks use the frontend-design skill.
- User-facing copy: plain language, no jargon; every governor/watchdog decision has a one-line reason.
- Settings: every new key goes in `const.DEFAULTS` and is validated in `settings.coerce`.
- Commit after each task with a `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` trailer.

## Review Focus

1. **Sensor missing** (no GPU counters, PDH fails, VM): governor treats the value as unknown and decides on the
   rest; never crashes, never pauses forever. → Task 3 test `test_unknown_gpu_is_ignored`.
2. **Close → reopen many times:** indexer stop/start must not leak threads, pools or processes. → Task 6 test
   `test_indexer_restarts_cleanly_three_times`.
3. **Upgrade from 0.6.x settings** (`pause_fullscreen: false` saved): becomes `games_mode: "off"`, not Smart. →
   Task 5 test `test_old_pause_fullscreen_setting_migrates`.
4. **Find bar shortcut already taken** by another app: main hotkey still works and the UI tells the user. → Task
   10 test `test_bar_hotkey_taken_keeps_main_hotkey`.
5. **Closing while a model download runs:** the download finishes (or is cancelled cleanly) and no half file is
   used. → Task 6 test `test_close_during_download_leaves_no_partial_model`.

### Task 3: Governor decision core

**Files:**
- Create: `nobadfind/governor.py`
- Test: `tests/test_governor.py`

**Interfaces:**
- Produces:
  - Levels: `FULL, GENTLE, LIGHT, PAUSED = "full", "gentle", "light", "paused"`; `ORDER = [PAUSED, LIGHT, GENTLE, FULL]`.
  - `CPU_CAP = {FULL: None, GENTLE: 35, LIGHT: 15, PAUSED: 5}` (percent of the whole CPU for the worker job).
  - `@dataclass Sample: t: float; cpu: float|None; gpu: float|None; mem_load: int; free_mb: int;
    find_cpu: float; foreground: str; game: bool; presentation: bool; hung: bool; battery: bool; call: bool;
    idle_s: float`
  - `@dataclass Decision: level: str; reason: str`
  - `class Brain:` `__init__(self, settings, apps)` (apps: the AppMemory from Task 4, or a fake with
    `start_level(exe) -> str|None` and `record_lag(exe, sample)`); `decide(self, s: Sample) -> Decision`;
    `pause_until: float` (user's "Pause for 1 hour").
  - `workers_for(level: str, plan: dict) -> int`: FULL → `plan["text_workers_idle"]`, GENTLE →
    `plan["text_workers"]`, LIGHT → 1, PAUSED → 0.
- Rules (exact starting values; tune later in one place, `governor.LIMITS` dict):
  `HOT_CPU=85, HOT_GPU=85, HOT_FOR=10s, LOW_FREE_MB=1500, STEP_UP_AFTER=30s, IDLE_AFTER=120s`.
  Order of checks: user pause → presentation → battery (if `pause_on_battery`) → call (if `pause_on_call`) →
  hung foreground or CPU/GPU ≥ HOT for HOT_FOR or free < LOW_FREE_MB (→ PAUSED, and `apps.record_lag` when a
  game/foreground app is known) → game with `games_mode` "always" → PAUSED; "smart" → cap at LIGHT (or the
  app's learned start level if lower); "off" → no cap → idle ≥ IDLE_AFTER and cpu < 50 → FULL → else GENTLE.
  Step down at once; step up one level at a time, only after STEP_UP_AFTER of samples allowing it.
  Reason strings (exact form): `"Paused: you asked for a break until 14:05"`, `"Paused: presentation or quiet
  time"`, `"Paused: on battery"`, `"Paused: microphone or camera in use"`, `"Paused: {app} isn't responding"`,
  `"Paused: the PC is busy (CPU 92%)"`, `"Paused: low on memory (900 MB free)"`, `"Light: {app} is running,
  so NOBAD Find uses 1 worker"`, `"Light: NOBAD Find learned to make room for {app}"`, `"Full: you're away"`,
  `"Gentle: you're using the PC"`. `{app}` = exe name without `.exe`.
