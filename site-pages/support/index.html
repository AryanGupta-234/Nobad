No telemetry

NOBAD VPN never sends crash reports or logs on its own. You decide what to share, and you see it before it leaves your PC.

01Report a bug

The fastest way is from inside the app, because it fills in the details for you:

  1. In NOBAD VPN, open Settings → Report a problem (or press Ctrl+K and type report).
  2. NOBAD saves a diagnostics zip to your Desktop (private keys removed), shows it in File Explorer, and opens a bug report on GitHub with your app version and Windows version already filled in.
  3. Describe what happened, drag the zip into the report, and press Submit.

Can't open the app? Report it on GitHub directly and tell us your Windows version.

Open a bug report → See known issues

A free GitHub account is needed to post. If you'd rather not create one, email ludmj99@gmail.com and attach the zip.

02After a crash

If NOBAD VPN closes unexpectedly, it saves a crash report on your PC and shows "NOBAD closed unexpectedly last time" the next time it starts. Press Report it there: the crash reports go into the diagnostics zip, and the bug report opens ready to submit. You can also Review report to read exactly what was saved.

If your internet stopped working after a crash, use the Start menu shortcut Restore internet (NOBAD) first: it removes NOBAD's firewall rules and tunnels even when the app isn't running.

04Try this first

  • No internet after disconnecting or a crash: Restore internet in the app, the tray menu or the Start menu. Quick repair also flushes DNS and renews your IP address.
  • A site won't open: the Intel tab's Know why tests DNS, TCP, TLS and HTTP and tells you which layer failed.
  • Windows says "Windows protected your PC": NOBAD isn't code-signed yet. Check the SHA-256 on the download page, then choose More info → Run anyway.
  • Running an old version? Install the latest from the download desk; your servers and settings are kept.

06Security issues

Please don't post security problems as a public issue. Report them privately through GitHub, where only the maintainer can see them. You'll get a reply, and a fix ships as a new release; reporters are credited unless they prefer not to be.
