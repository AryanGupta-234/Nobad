What it does for you

Your server, as close as your desktop.

A desktop file manager for the servers you work on: connect, move files, edit them and deploy, without a terminal.

01 / Connect safely

The right server, every time.

Connect over SFTP or FTP/FTPS, with the server's identity checked before anything moves.

  • Host keys verified. An unknown host asks you first, and a changed key is refused by default.
  • Logins locked away. Saved logins are encrypted with your master password.
02 / Work like it's local

Both sides, side by side.

Your files and the server's in two panes, so moving and editing feels like any folder on your PC.

  • Edit in place. Edit a file on the server; if it changed there meanwhile, you see both versions side by side.
  • Two-way sync and transfers. Sync folders both ways and queue uploads and downloads with progress, retry and cancel.
03 / Ship with confidence

Deploy with a way back.

Push changes to your servers knowing you can undo them if something goes wrong.

  • Backups first. Deployments come with backups of what they replace.
  • Health checks and rollback. Check the result after a deployment, and roll back if it fails.

Features

Built for the files you can't lose.

What NOBAD File Bridge is being built to do. It's still in development, so treat this as the plan for its first release.

Browse

Dual pane

Local and remote files side by side, over SFTP or FTP/FTPS.

Transfer

Transfer queue

Progress, retry and cancel. Files are written as .part until complete, so a cut-off transfer never looks finished.

Relay

Server to server

Copy files from one server straight to another.

Sync

Two-way sync

Knows what changed on each side since last time. When both sides changed a file, you decide, file by file.

Edit

Remote editing

Edit a file on the server, with conflict detection and a side-by-side diff.

Terminal

Built-in terminals

Server and local terminals, right next to the files they work on.

Vault

Password vault

Saved logins encrypted with your master password; saved secrets kept in your system's keyring.

Deploy

Deployments

Deploy to your servers with backups, health checks and rollback.

How it works

Three steps, no terminal.

From your desktop to your server and back.

  1. 01

    Connect

    Open a server over SFTP or FTP/FTPS. Its host key is checked before you go any further.

  2. 02

    Browse and move

    See both sides at once. Drag files across; transfers wait in a queue with progress, retry and cancel.

  3. 03

    Sync, edit, deploy

    Sync folders both ways, edit remote files safely, or run a deployment with backups, health checks and rollback.

Security

It holds your keys. It keeps them.

A file manager holds the keys to your servers. These are the protections it's built around.

Encrypted password vault

Saved logins are encrypted with your master password. Saved secrets live in your operating system's keyring.

Argon2id + AES-GCM

Host keys verified

An unknown server is shown to you before you connect. A server whose key has changed is refused by default.

On by default

No tracking

No accounts, ads or telemetry. Your files and logins go between your PC and the servers you connect to.

FAQ

Questions, answered.

Anything else? Ask on GitHub Discussions.

Can I download it yet?

Not yet. NOBAD File Bridge is still being finished and hardened. When the first release is ready, it will appear on this page and on the download desk.

Which computers will it run on?

Linux and Windows.

Which servers can it connect to?

Any server you can reach over SFTP (SSH) or FTP/FTPS: a website host, a VPS or your own machine.

Where are my passwords kept?

On your computer: saved logins are encrypted with your master password, and saved secrets are kept in your operating system's keyring.

Will it cost anything?

It's open source under the MIT License, like every NOBAD product.
