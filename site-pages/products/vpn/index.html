03 / Network Intelligence

KNOW
WHY.

"The site doesn't open" turns into evidence: which layer failed, who is likely responsible and what will actually fix it. Everything is measured live on your PC.

  • DNS intelligence. Compares your network's resolver with independent and encrypted resolvers across A, AAAA, CNAME, MX, TXT, NS and SOA records.
  • Filtering and sinkholes. Spots RPZ-style redirects, invented answers and DNS interception without a hardcoded list of ISPs.
  • Layer by layer. Tests DNS, TCP, TLS, HTTP, IPv4 and IPv6 separately, so a DNS block is never mistaken for a site-name block.
  • VPN integrity. Checks that IPv4, IPv6 and DNS really go through the tunnel while you're connected.
  • Learns your networks. Local baselines notice when a network changes. History never leaves this PC.
  • Smart fix agent. Off until you switch it on. It saves your DNS settings first, verifies the fix and undoes it if anything breaks.

04 / Fail-safe

NEVER
OFFLINE.

If NOBAD is killed, crashes or is uninstalled in the middle of a change, Windows still gets its network settings back exactly as they were. You never need a terminal.

Step 1

Restore

Removes NOBAD's firewall rules, tunnels and recorded DNS changes. Nothing else is touched.

Step 2

Quick repair

Also flushes DNS, clears the ARP cache and renews your IP address. Takes seconds.

Step 3

Full reset

Also resets Winsock, TCP/IP and proxy settings, like Windows' own network reset. Needs a restart.

06 / Compatibility & disclosure

THE
DETAILS.

Facts taken from the current build and its source. Anything that isn't verified is left out rather than guessed.

Supported operating systems
Windows 10 version 1809 or later and Windows 11, 64-bit. ARM64 PCs run the app through Windows' x64 emulation and use the native ARM64 WireGuard.
VPN protocol
WireGuard, through the official WireGuard for Windows tunnel service. Setup installs it if it's missing, and NOBAD only runs WireGuard installers signed by WireGuard LLC.
Encryption & key handling
WireGuard's own cryptography (Curve25519, ChaCha20-Poly1305, BLAKE2s). Configs and keys stay on this PC, in a folder only administrators and SYSTEM can read. Optional Windows DPAPI encryption protects copies and backups.
Servers & logging
NOBAD VPN is a client. It connects to the WireGuard servers in the configs you import, so the server-side logging policy is your provider's. The app keeps its logs, usage and diagnostic history on this PC. Crash reports are off unless you opt in.
Permissions & network behavior
Needs administrator rights. After that, setup's launcher task means no UAC prompt. The kill switch and DNS leak block use Windows Firewall rules. Adapter settings are only changed by the smart fix agent, after you switch it on, and every change is recorded so it can be undone.
Outbound connections
Your VPN servers. At every launch, a connectivity check (a ping to 1.1.1.1 and one test DNS lookup) and, unless you switch it off, IP-location lookups via ipinfo.io for your exit address and the server map. Everything else runs only when you start it or opt in: the speed test and service checks, Network Intelligence probes, the WireGuard download fallback and the update check (only if an update URL is set).
Support
Bugs and questions: GitHub Issues. Security problems: report them privately via private vulnerability reporting. Anything else: ludmj99@gmail.com.
Responsible use
NOBAD VPN is a client: it doesn't run VPN servers, sell access or keep logs, and you bring configs from a provider you choose. VPN use, and streaming services' own terms, vary by country and by service. Using a VPN doesn't change which laws or terms apply to you, so check them for where you are.
