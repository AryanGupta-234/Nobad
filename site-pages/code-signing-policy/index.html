How the Windows releases of NOBAD VPN are built and signed, and who is responsible for them.

NOBAD · independent, free and open sourceApplies to NOBAD VPN for WindowsUpdated 12 Nov 2026
01Signing 02What is signed 03Team roles 04Privacy 05Reporting problems
Current status

NOBAD VPN releases are not code-signed yet. An application for free code signing for open-source projects (SignPath Foundation) is being prepared. Until a release is signed, verify the SHA-256 published with each GitHub Release.

01Signing

Once approved, Windows binaries will be signed through SignPath.io, with a certificate issued to the SignPath Foundation, which offers this free of charge to open-source projects. The private key stays in SignPath's hardware security module; NOBAD never has it.

02What is signed

  • Only binaries built from this project's own source code: NobadVPN.exe and its installer NobadVPN-Setup-<version>.exe.
  • Every signed release is built automatically by GitHub Actions from a tagged commit in the public repository github.com/AryanGupta-234/Nobad.
  • The official WireGuard for Windows installers bundled with NOBAD VPN are not re-signed. They keep WireGuard LLC's own signature, which NOBAD verifies before bundling and before installing them.
  • Product name and version are set on every binary.

04Privacy

NOBAD VPN doesn't collect telemetry, and it doesn't transfer information to other networked systems unless you ask it to, or switch on a feature that needs it. See the privacy policy for every connection it can make and when.

05Reporting problems

Security issues: report them privately via GitHub private vulnerability reporting. Other issues: GitHub Issues, or email ludmj99@gmail.com.
