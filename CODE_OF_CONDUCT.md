# Code of conduct

NOBAD follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, give and accept constructive feedback, and focus on what is
best for the people who use NOBAD. Harassment, insults and personal attacks are not tolerated.

To report unacceptable behaviour, open a private security advisory on the repository (see [SECURITY.md](SECURITY.md))
or contact the maintainer through the GitHub profile. Reports are handled confidentially.
